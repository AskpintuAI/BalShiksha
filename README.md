# BalShiksha: Kids Learning Universe

## Technical Setup
- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS (Playful/Bold theme)
- **Animations:** Framer Motion
- **Rewards:** Canvas Confetti
- **Audio:** Web Speech API (TTS) + Howler.js (Sound effects)
- **Content:** Multi-language (English, Hindi, Tamil, Chinese, Numbers)

## Levels
1. **Numbers & Basics:** 1-10 with visual associations.
2. **Alphabets (Multi-lang):** Letters with objects (A for Apple, अ for अनार).
3. **Simple Words:** Easy 3-4 letter word pairings.
4. **Difficult Words:** Complex vocabulary.

## Accessibility
- **Screen Reader Support:** ARIA labels for all interactive elements.
- **Visual Cues:** High-contrast modes and visual indicators for sounds (for deaf users).
- **Audio Feedback:** Descriptive narration for everything on screen.

## Future Proofing
- Modular content structure in `src/data/` for easy additions.
- Apollo/Gemini integration for dynamic content generation.
